PRONTO artwork

pronto-icon.png is the original generated application mark. pronto.ico contains
16, 24, 32, 48, 64, 128 and 256 pixel Windows icons. favicon.png is the 64 pixel
web version. All use the same navy, white and teal P mark, with transparent
outer corners. The smaller files are format and size derivatives only.

The artwork was created for PRONTO with the built-in image_gen tool. The design
brief was a calm scientific workstation identity: a white P with a curved teal
strand, suggesting genomic data becoming a report. It is not an institutional
seal or an official hospital logo.

Generation prompt

Use case: logo-brand. Asset type: production Windows desktop application icon
for PRONTO, a professional molecular pathology / bioinformatics reporting
workstation. Design one exceptionally crisp, sophisticated icon, isolated,
square canvas 1024 x 1024. A deep ink navy (#12293D) rounded-square tile with
restrained corner radius and generous quiet margin, no shadow outside tile,
transparent outside the tile. Inside it, a bold custom white P-shaped monogram
whose counter is an elegant curved loop suggesting a single strand of genomic
data becoming a report. Integrate one short teal (#12AAA1) signal ribbon into
the vertical stem/loop, just enough to hint paired DNA sequence without drawing
a generic double helix. Strong graphic silhouette, refined optical balance,
very simple broad geometric forms, flat vector-like artwork, beautiful at 16,
24, 32 and 256 pixels. Use only navy, warm white, and teal. Centered symbol
approximately 65 percent of canvas; tile approximately 92 percent. This is a
serious Scandinavian scientific desktop instrument, precise, calm and
distinctive. No text or wordmark, no letters other than the single abstract P,
no medical cross, no shield, no microscope, no magnifier, no sparkles, no
circuit board, no gradients, no 3D bevel, no shiny plastic, no mockup, no
presentation sheet, no border frame. Deliver exactly one finished icon, not
alternatives.
